# P7 双臂 O6 双手控制站

基于 WSL 2 和 Tkinter 的控制界面，用于识别及操作 P7 双臂、O6 双手并显示三路 Orbbec RGB 画面。机械臂通信使用 linkerbot SDK；设备需通过 USBIPD 转发到 Ubuntu。

## 新电脑安装

将仓库文件放在 Windows 11 的项目文件夹（例如 D 盘）中，双击 `20261109_new_pc_setup.bat`。按提示授权；若需要重启，重启后再次运行。首次启动 Ubuntu 时创建 Linux 用户名和密码。需要联网、开启虚拟化及 Windows winget。Ubuntu 默认安装位置由 WSL 决定。

安装脚本会下载固定版本的厂商 SDK 并检查 PCAN 模块；缺少模块时需另行处理。此安装流程尚未在全新电脑上完整验证。

## 启动

连接四个 PCAN 及三个 Orbbec 后，双击 `20261109_start_p7_windows.bat`。脚本查找并转发设备，并可能请求管理员授权或 Ubuntu sudo 密码。打开界面后点击“识别设备”，再分别连接机械臂和手。设备的物理左右关系需在现场确认。

## 当前限制

机械臂控制仍使用曾出现晃动和指令积压的旧分段逻辑，问题尚未修复。停止或恢复零位不会清除 SDK 中已经积压的指令，旧指令可能继续发送。使能请求成功不等于驱动器确认使能。连接、使能或关闭程序时腕部可能松动，须可靠支撑并确保现场实体急停可用。远程操作不能替代现场监护。

更多实现细节见 `20261109_P7上位机程序逻辑.md`。
